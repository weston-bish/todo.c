# ToDo.c
A simple todo list app written in C that can add, list, and remove items from a list.
I want to do more low-level projects in the future, so I thought starting with a todo list in C was a great idea to refresh my memory.

## To Compile:
`gcc -Wall -Wextra -std=c11 todo.c -o todo`

## Usage:
Try `./todo help`
